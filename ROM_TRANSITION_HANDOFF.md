## 3. Architecture in one page
- **Contract** (`ROM_TRANSITION_CONTRACT.md`): v1 + Appendix B (v2 execution: child capture at the boundary, v9 mailbox 876 bytes, SDR2 result) + Appendix C (v2.1: byte layout C.1, word tables C.2, enums C.3, child transport C.4, perf rule C.5, **C.6 request flags + worker stop rule**).
- **SDR2** result: 64-byte header (`SDR2`, fmt 1, total, CRC32 over buf[12:total] with the CRC field zeroed, requestId, status, boundary 0-3, mode, policy, record count, turn, both RNG quads), then records `tag u16, payload_bytes u16, payload` padded to 4. Tags: 1 party 12x32, 2 active 2x37, 3 field 1x6, 4 side 2x12, 5 battle 1x10, 6 rng 1x8, 7 legal Nx4, 8 trainer action 1x3, 9 events (variable), 10 terminal 1x2, 11 unsupported/error 1x2. Nonterminal success = tags 1-9; terminal = 1-6,8,9,10 (no tag 7); nonzero status = only tag 11. Reference encoder: `tools/rom_oracle/make_sdr2_vectors.py`; golden vectors `tools/rom_oracle/sdr2_vectors/` (synthetic wire examples, not ROM-derived); the ONLY production decoder is `tools/rom_oracle/sdr2.py`.
- **v9 request** = v8 864 bytes + `resultAddress u32@864, resultCapacity u32@868, resultVersion u16=1@872, flags u16@874` (bit0 compact result, bits1-2 difficulty override: 0 keep, 1 easy, 2 normal, 3 refused; all other bits zero). The ROM announces `ROMTRACE|ready|<req_addr>|876|9|3|<result_addr>|8192`; never use a caller-chosen address. The **hook emits `ROMTRACE|binary-ready|addr|len` LAST**; the worker stops and saves the child there (`native/rom_worker/stop_policy.h`, `result_tags.h`).
- **The v9 ELF rejects every v8 request** (`request->version != 9`); the contract sentence "a v8 request uses the old trace path" was never implemented. Consumers (`rom_eval.py`, `rom_query.py`, `run_dynamic.py` legacy paths, E's `rom_diff_harness.py`) still speak v8 and the 4-field ready line: **migrating them to v9 with flags bit0 clear (trace path; helper `run_dynamic.encode_v9_trace_request`) is package D's job and is required before the ELF flips.** Plan: the ELF flips ONCE, at Gate F.
